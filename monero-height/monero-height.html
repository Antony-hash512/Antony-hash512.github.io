Зачем это нужно?

При восстановлении кошелька Monero (CLI, GUI, Cake Wallet, Feather) указание точной высоты блока позволяет начать сканирование с нужного момента, сокращая время синхронизации с часов до минут.

100% клиентское приложение. Работает без сервера, запросы отправляются напрямую к открытому API xmrchain.net.
